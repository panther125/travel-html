一份手记，
写给也读盗墓的你。

2020 年第一次在明德楼摸到 C/C++，吵闹的教室里没人想到我会一头扎进代码。同年在寝室迷上网络游戏，年底开始学 Python——人生的岔路口从来不会提前打招呼。

2021 年初摸了摸 Java，觉得枯燥无味；剩下的月份，又老老实实回去啃 Java 基础。后来撞上 WordPress，兴之所至搭了第一个个人博客——上半年捣鼓博客，下半年继续学 Java，现在正学 JavaWeb。

喜欢开发，喜欢研究逻辑算法，眼里容不下一个小 Bug。而未来——想成为一名算法工程师。

这份《盗墓笔记》纪年档案，是我把三叔铺的局、铁三角走过的路，按故事内时间重新捋了一遍的产物。不为别的，同好读着顺，就好。

  • 2020初遇 C/C++，明德楼；年底转向 Python。
  • 2021初识 Java，啃完基础；搭起第一个 WordPress 博客。
  • 2022学 JavaWeb；整理《盗墓笔记》纪年档案上线。
  • 未来想做一名算法工程师——把每一条线索都收敛成最优解。
